I've written before about the [pc-ctx CLI](/blog/pc-ctx-cli-design/) and the [MCP server](/blog/pc-ctx-mcp-server/). This post is about the face I put on it: a React dashboard that reads from the same GitHub repo, served by a Hono Worker on Cloudflare Pages.

```
Browser → Hono Worker → GitHub GraphQL API → context repo
                     ↓
              React SPA
         (served by Worker)
```

The Worker proxies the GitHub GraphQL API and serves the SPA. For my personal instance the whole site sits behind Cloudflare Zero Trust. The public demo at demo-pc-ctx-web.pages.dev has auth disabled.

You can also serve the SPA locally via `ctx ui --serve` — the CLI downloads the latest release and runs it with a local Hono proxy to the GitHub API.

## Dashboard

![Dashboard overview](/blog/pc-ctx-web-ui/dashboard.png)

The dashboard shows counts per domain, a status distribution bar, weekly activity, and a timeline of recent progress. All animated with framer-motion.

## Browse

![Plans page](/blog/pc-ctx-web-ui/plans.png)

Each plan card shows status, category, priority, and task progress. Clicking opens the detail view with full task breakdown and rendered markdown.
